# Banking Management System

A simple Banking Management System built using Python and Object-Oriented Programming.

## Features

- Create a new bank account
- Deposit money
- Withdraw money
- Check account details
- Update account details
- Delete bank account
- JSON file used for data storage

## Technologies Used

- Python
- OOP
- JSON
- File Handling

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python main.py
